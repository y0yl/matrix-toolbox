# Matrix Toolbox 🧮

矩阵运算工具箱 — 行列式 · 特征值 · 参数化简 · AI解题

**🔗 在线体验：** http://8.137.213.69:6130

## ✨ 功能

### 基本运算
- ➕ 矩阵加法 / 减法 / 乘法 / 数乘

### 变换化简
- 📐 行阶梯形 (REF)
- ✅ 行最简形 (RREF)
- ↕️ 转置
- 🔄 逆矩阵

### 性质求解
- 📏 行列式
- 📊 秩
- Σ 迹
- 🧮 余子式 / 伴随矩阵
- λ 特征值 & 特征向量

### 性质证明
自动验证 10+ 条矩阵恒等式：
- `(AB)ᵀ = BᵀAᵀ`
- `det(AB) = det(A)·det(B)`
- `A·A⁻¹ = I`
- `tr(AB) = tr(BA)`
- ...

### 🔤 参数矩阵化简
支持含参表达式的矩阵运算：
- 输入 `λ-1, 2, 3` 等符号表达式
- 支持单参数 / 多参数：`λ`, `a`, `2a-3b+1`
- 自动进行参数化 RREF / REF / 行列式 / 秩
- 每步展示完整化简过程

### 🤖 AI 解题
- 输入任意线性代数问题，AI 给出解题步骤
- 支持 LaTeX 公式渲染
- 智能队列管理（最多 3 并发，实时排队反馈）

## 🚀 部署

```bash
# 克隆
git clone https://github.com/y0yl/matrix-toolbox.git
cd matrix-toolbox

# 启动
node server.js

# 访问 http://localhost:6130
```

**依赖：** Node.js 18+ （无第三方依赖）

## 📝 技术细节

- **符号计算引擎：** 自研 `SymExpr` + `SymFrac` 类，支持多项式表达式的加减乘除
- **精确分数：** 所有数值运算基于 `Fraction` 类，避免浮点误差
- **异步 AI：** `exec` 替代 `execSync`，并发控制防崩溃
- **零依赖：** 纯 Node.js 原生实现
